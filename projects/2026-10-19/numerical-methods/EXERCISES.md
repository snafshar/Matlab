# Numerical Methods Exercises

1. Change the bisection tolerance and chart the number of iterations.
2. Demonstrate Newton's method failing when the starting value has a zero derivative.
3. Compare golden-section search with a grid search over the same interval.
4. Fit a line to noisy observations and discuss the residual norm.
5. Explain why power iteration may fail to reveal a desired eigenvector when the initial vector is orthogonal to it.
6. Compare central finite differences at several step sizes; explain truncation and round-off error.
7. Add a tolerance check to the regression test for invalid input.
8. Add a vectorized example and compare it with the scalar implementation.

Keep the assumptions of each method visible in function documentation.
